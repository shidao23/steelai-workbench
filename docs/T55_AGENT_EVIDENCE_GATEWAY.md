# T55 Agent 证据网关

版本：`SteelAI Workbench 0.17.0-agent-evidence-gateway`
状态：完成
适用入口：**研究助手 → 智能助手**

## 目标

T55 在七个只读科研工具与云模型之间增加一个关闭式失败的证据网关。云模型只能读取已核验、已获准、已脱敏并带证据身份的结构化结果；它不能批准建议、写入正式科研数据、启动模型任务或执行任意 Shell。

网关不是新的科研计算引擎。数据质量、Physics 计算、统计规则和图像模型人工复核仍由 T51–T54 的确定性模块负责。

## 调用链

```text
研究问题
  → 隐私预检与发送摘要
  → 固定只读工具白名单
  → 来源资格检查
      processed/Physics → T52 数据契约 passed
      EBSD/SEM           → T54 人工复核结果 complete
      表述边界           → 确定性证据验证规则
  → 删除敏感字段并扫描敏感值
  → 分配 AGEVID 证据身份
  → 云模型
  → 五段式受限解释
  → 不含原文的仅追加审计包
```

## 发送前隐私边界

下列内容在 API 调用前阻断：

- Windows 盘符路径和 UNC 路径；
- CTF、ANG、TIF/TIFF、HDR、Zarr、模型权重等受保护文件名；
- 疑似 API Key、Token 或 Secret；
- `path`、`filename`、`source_locator`、`raw_*` 等敏感字段；
- 不在固定参数契约中的额外工具参数；
- 非 JSON 结构化工具输出。

页面在运行前显示供应商、模型、问题字符数、问题 SHA-256 和计划开放的只读工具。发送摘要和运行审计都不保存问题、回答、工具参数或工具载荷原文。

## 证据资格

| 工具类别 | 放行条件 | 放行结果 |
| --- | --- | --- |
| 样品、比较、Physics | T52 研究数据契约为 `passed` | `real_research_data` 结构化证据 |
| 证据验证摘要 | 固定确定性政策 | 表述与边界参考 |
| EBSD | 至少一项 T54 EBSD 结果已人工接纳且完整性有效 | `model_output`，不等于实验真值 |
| SEM/AutoDimple | 至少一项 T54 SEM 结果已人工接纳且完整性有效 | `model_output`，不等于实验真值 |

没有合格来源时，网关返回 `GOV-EVIDENCE-001`，且不会执行该工具。来源摘要与脱敏载荷共同生成 `AGEVID-*` 身份，供后续工具轨迹和审计反查。

## 受限解释契约

回答固定归一化为五个区段：

1. 已确认事实；
2. 当前判断；
3. 待验证假设；
4. 证据与局限；
5. 下一步行动。

缺失区段会标为 `warning`。任何输出都固定声明：不能代替人工批准、不能正式写入、不能执行 Shell、不能自动成为科学结论，并要求人工复核。页面只能将其显式保存为“待人工复核的 Agent 草稿”，不再称为项目证据。

## 审计包

正常界面调用发布到被 Git 忽略的 `outputs/agent_gateway/<gateway_id>/`：

- `send_summary.json`：供应商、模型、问题摘要、调用轮次、工具白名单、证据身份和隐私/权限声明；
- `agent_run_audit.json`：状态、调用摘要、证据引用、Token 用量和失败类型；
- `restricted_output_contract.json`：五段式结构的计数和权限边界；
- `governance_manifest.json` 与 `COMPLETE`：共享治理身份、来源引用和完整性封印。

审计只保存哈希和计数。供应商 response ID 也只保存摘要；原始异常信息不写入包。相同包不能静默覆盖，篡改后验证为 `invalidated`。

## 离线与失败行为

- 未配置 API Key 时，Agent 保持 `offline`，其他确定性科研功能照常运行；
- 问题隐私检查失败时，不创建客户端、不发送 API 请求；
- 工具证据不合格时，只向模型返回通用阻断码，不泄露本地错误细节；
- 模型回答泄露路径或受保护文件名时，回答在页面展示前清空并标为 `blocked`；
- 审计发布失败时，本次回答不放行，临时目录清理。

## 验证

专项测试覆盖：隐私字段删除、敏感值阻断、数据契约门禁、图像结果人工复核门禁、非法审批/写入/Shell 工具、五段式输出、回答泄露阻断、脱敏审计包和无 Key 离线运行。测试全部使用合成夹具和模拟客户端，不调用真实云端 API，也不读取或改写原始实验数据。
