# T64 三分钟演示脚本

## 0:00–0:30 研究问题

打开科研总览，说明系统不是聊天机器人，而是把材料科研拆成数据、物理、统计、证据和成果几个可核验环节。指出 AI 只建议，确定性代码执行，人工保留决定权。

## 0:30–1:10 可追溯主链路

进入 T40 旗舰演示，运行公开合成成功链路。展示陌生 CSV、字段建议、人工决定、SteelData QC、SteelStats 组级统计和描述性解释。强调每一步都生成来源、状态、摘要和完整性标记。

## 1:10–1:35 失败关闭

展示未知单位案例。说明系统不会猜单位、补零或继续产出统计，而是停在 `needs_human` 并保留失败原因。这是可信科研系统必须有的路径。

## 1:35–2:10 真实钢铁案例

进入 T62，说明 UCI Steel Plates Faults 的来源、许可证、固定数据划分、基线和 CPU kNN。展示指标和错误分析，同时明确它不是成分—性能模型，也不支持工艺推荐。

## 2:10–2:40 受治理 Agent

进入多智能体协作，展示 T60/T61 的角色、MCP 工具和 A2A 任务信封。说明角色不能审批、正式写入或运行任意命令，云端不可用时确定性步骤仍能运行。

## 2:40–3:00 价值如何验证

展示 T63 评测设计：同一任务集、三种流程、双重复和冻结指标。最后说明在真实 24 条测量完成前，系统只展示评测方法，不把界面演示包装成效率结论。
