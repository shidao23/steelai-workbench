# T56 统一运行与成果中心

版本：`SteelAI Workbench 0.18.0-run-results-center`
状态：完成
入口：**研究助手 → 运行与成果**

## 目标

T56 把 T52–T55 已形成的治理运行、科研会话、自动化任务和 T40 冻结演示集中到一个只读页面。用户可以直接区分进行中、待人工确认、被阻止、完整性失效、已完成和已验收成果，并从当前记录跳回正确的工作区。

中心不执行任务、不改变审批、不修复或覆盖结果包。它只读取固定目录和已有 Manifest，生成轻量内存索引。

## 统一记录

每条记录统一包含：

- 任务 ID 与模块；
- 原始状态和统一状态组；
- 完整性状态；
- 更新时间；
- 审核身份；
- 结果等级和证据类别；
- 相对于项目根目录的结果位置；
- 作品集资格和原因；
- 返回来源工作区的下一步入口。

中心读取的固定来源包括数据接入治理包、Physics 运行包、治理统计包、图像任务/运行/复核包、Agent 网关审计包、科研会话、AutoDimple 自动化状态和 T40 旗舰演示。不会递归搜索任意用户目录，也不会在页面显示绝对路径。

## 状态分组

| 页面状态 | 原始状态示例 | 含义 |
| --- | --- | --- |
| 进行中 | `planned` `active` `approved` `running` | 尚在准备或执行，不是成果 |
| 待人工确认 | `draft` `needs_human` `warning` | 必须由人确认或接受警告 |
| 被阻止 | `blocked` `rejected` `failed` `canceled` | 需要回到来源模块处理原因 |
| 完整性失效 | Manifest、标记或文件摘要不一致 | 不能复用、覆盖或作为证据 |
| 已完成 | `passed` `complete` `completed` | 技术流程结束，但不一定能进作品集 |
| 已验收成果 | 通过作品集四项门禁 | 可以进入作品集候选 |

## 作品集四项门禁

治理结果只有同时满足下列条件才进入作品集：

1. Governance Manifest 完整性为 `passed`；
2. 治理状态为 `complete`；
3. 结果等级为 `accepted_evidence`、`model_result` 或 `human_conclusion`；
4. 存在绑定当前对象身份的具名人工 `approved` 或 `warning_accepted` 记录。

Agent 网关回答即使运行完成，结果等级仍是 `working_candidate`，因此不能进入作品集。科研会话、自动化状态和活动日志同样不是成果。

T40 是治理内核建立前冻结的公开合成演示。它必须同时通过原 T40 完整性校验，并出现在 `config/portfolio_acceptance_v1.0.json` 的显式人工验收登记中；进入作品集时固定标记为 `synthetic_demo_data` 和“仅展示工程能力”，不能冒充真实实验结论。

Career Portfolio 页面还会再次执行相同的 complete、完整性和审核身份检查。项目活动日志保留供过程追溯，但不再作为作品集成果来源。

## 页面与导航

科研总览新增“统一运行与成果”快捷入口。中心提供七种筛选，并在选择某条记录后显示其资格原因与技术详情，再直接跳转到数据质控、Physics、统计、图像复核、模型实验室、智能助手、科研会话或旗舰演示。

该实现只进行小规模目录枚举、JSON/Manifest 校验和表格渲染，不加载原始图像、模型权重或大型数据集，适合普通个人电脑运行。

## 验证

专项测试使用合成治理包验证：统一字段、相对路径、状态筛选、人工验收、篡改失效、Agent 中间结果排除、科研会话和自动化可见性、T40 双门禁、作品集防御性过滤以及非法验收登记拒绝。完整项目测试继续不需要云端 API。
