# T52 数据接入与 Physics Engine 共享治理适配

状态：`Done`
依赖：T51 共享科研治理包
实施日期：2026-09-09

## 1. 目标

T52 不重写已经验证过的数据校验和物理公式，而是在它们外层接入 T51 公共治理内核。标准 CSV、SteelData 与 Physics Engine 因而使用同一套研究对象身份、摘要绑定人工批准、状态转换、来源、QC、Governance Manifest、完整性验证和仅追加发布规则。

## 2. 数据接入链路

两条入口共享 `steelai.data_intake_governance`：

1. 输入注册：记录入口类型、目标表、内容 SHA-256、字段和行数。
2. 确定性建议：复用数据契约和编号策略生成预检结果，不由 AI 判定是否可写。
3. 人工审批：审核人、理由、决定时间和当前对象摘要一起保存；摘要变化后旧批准失效。
4. 受控执行：只有 `approved` 可进入 `running`，提交前在写入锁内重新校验。
5. QC 与提交：通过后只追加到登记的 `data/processed/` 表；警告完成必须另有 `warning_accepted` 快照。
6. 审计发布：在 `outputs/governed_data_intake/<intake_id>/` 保存标准化快照、预检、提交结果、治理记录、Manifest 和 `COMPLETE`。

SteelData 入口还会重新校验其结果包和审批摘要、重建候选行并核对用户刚刚复核的 preview SHA-256，然后才进入同一个最终闸门。SteelData 的原始结果包保持不变。

## 3. 数据关闭式规则

| 情况 | 治理状态/错误码 | 行为 |
| --- | --- | --- |
| 未知单位 | `needs_human` / `GOV-UNIT-001` | 不生成标准化暂存结果，不写入，不进入统计 |
| 缺少必要值或列 | `blocked` / `GOV-SCHEMA-001` | 不以 0 或空字符串代填 |
| 样品/试样对应冲突 | `needs_human` / `GOV-IDENTITY-001` | 必须修正身份关系后重新预检 |
| 本批或既有主键重复 | `blocked` / `GOV-DUPLICATE-001` | 拒绝覆盖原记录 |
| 未具名批准 | `draft` 或 `needs_human` / `GOV-APPROVAL-001` | 不能进入执行 |

正式表的保护仍由原有提交锁、目的地白名单、提交前重检和临时文件原子替换承担；T52 在其上增加统一审批与可验证审计包。

## 4. Physics Engine 链路

`steelai.physics_governance` 先使用现有模型注册表完成即时预览，正式保存时生成稳定 `PHYSICS-...` 运行身份，并记录：

- 样品 ID、只包含已提供字段的成分快照和来源状态；
- 六个所选公式的模型 ID、版本、公式、必要输入、输出单位、适用范围、审核和校正状态；
- 每个结果、适用性警告和固定标签 `empirical_model_estimate_not_experimental_truth`；
- 匹配实验观测及独立残差 `model_value - experimental_value`；
- 具名批准、范围警告接受、完整状态轨迹、逐模型 Markdown 卡和 Governance Manifest。

缺少任一必要输入时，该公式返回 `None`/`skipped_missing_inputs`，整个正式运行关闭式阻断，绝不把缺失成分按 0 代填。超出适用范围时允许查看估算预览，但必须由人工显式接受警告才可保存模型结果包。

正式包发布到 `outputs/physics_runs/<run_id>/`。完全相同的输入、所选公式和实验对照会复用同一完整包；如果既有包内文件、Manifest 或完成标记被改动，验证状态为 `invalidated`，不会被重跑覆盖。

## 5. 页面结构

数据接入和 Physics 页面统一使用以下阅读顺序：

1. 当前状态；
2. 主要操作；
3. 结果；
4. 技术详情；
5. 下一步。

页面只把明确的人工作决定传给治理适配器。预览、即时公式计算和 AI 建议均不等于批准，也不会自动触发正式写入。

## 6. 验收与边界

离线专项测试验证未知单位、缺失输入、越界警告、未批准、正常提交、两路契约一致、重复主键、幂等复用和包篡改。全部测试使用临时目录与合成夹具，不读取或修改真实科研资料。

T52 不迁移旧数据、不改写历史结果包、不改变 T40 冻结演示、不训练或校正模型，也不把 Physics 模型值冒充实验真值。可追溯统计、EBSD/SEM、研究助手、模型实验室、自动化、科研会话和作品集仍由后续任务逐项接入共享内核。
