# T75 双道次软化分析

## 当前状态

T74 的 16 行正式特征已经完成具名批准和治理入库。项目负责人已于 2026-09-11 冻结 T75 方法：2% 偏移法作为静态再结晶软化率主方法，5% 定真应变法作为敏感性对照；0.2% 偏移法暂不发布正式结果。

## 本批分辨率证据

对 16 个 DH 采集、32 个有效加载段的局部真应变网格检查得到：

- 最小正应变步长约 `0.003226`。
- 中位正应变步长约 `0.004068`。
- 0.2% 偏移量为 `0.002`，只相当于约 `0.49` 个中位采样步长，低于当前数据的单步分辨率。
- 2% 偏移量为 `0.02`，相当于约 `4.92` 个中位采样步长，数值上更容易稳定识别。

“至少覆盖 3 个中位采样步长”只是 SteelAI 的分辨率报警规则，不是文献标准。它只能说明数值可辨性，不能替代冶金方法选择。

## 候选方法

1. **0.2% 偏移法**：常被解释为包含回复和再结晶的机械总软化；本批分辨率不足，结果可能高度依赖拟合窗口。
2. **2% 偏移法**：文献常用于更聚焦静态再结晶的机械估计；本批应变网格数值上可辨。
3. **5% 定应变法**：T74 已直接提供局部真应变 0.05 的两道次流动应力，但其应力定义和分母仍需按所选论文固定。
4. **平均流动应力法**：需要先明确两个道次的积分区间。

Cambridge 的方法比较研究指出，2% 偏移法与 5% 定应变法在无析出影响的被测钢中较一致；有析出参与时，方法适用性会变化。SAGE 的限制研究列出六种常见方法，并强调材料流动行为会影响特征应力的选择。因此不能仅凭“常用”二字冻结唯一结果。

## 已批准方法与计算定义

统一使用 `X=(sigma_m-sigma_2)/(sigma_m-sigma_1)`，且不把超出 0–1 的原始结果截断。

- 主方法 `offset_2p0_srx_focused`：同一局部应变的重复点先取应力中位数；分别用两道次 `0 < epsilon <= 0.02` 的唯一点拟合初始直线，要求至少 4 点、正斜率且 `R² >= 0.75`。将直线沿真应变平移 0.02，取偏移线与实测曲线的首个交点；只在相邻点之间线性插值，禁止外推。`sigma_m` 取 T74 第一道次峰值应力。
- 对照方法 `fixed_true_strain_0p05`：`sigma_1`、`sigma_2` 直接使用 T74 在局部真应变 0.05 的插值应力。`sigma_m` 按文献中的“未软化连续第一道次”含义，用第一道次 `epsilon >= 0.05` 的正应力点拟合 Hollomon 关系 `sigma=K*epsilon^n`，并投影到“第一道次最大局部真应变 + 0.05”；要求至少 10 点且 `R² >= 0.90`。该 `sigma_m` 是模型投影，不是实测点。
