# 已知限制

- 当前毕业主线只正式覆盖拉伸性能的屈服强度、抗拉强度和伸长率；成分、曲线、冲击、硬度、SEM、EBSD 和 XRD 尚未形成同等级端到端数据契约。
- 公开旗舰演示使用合成数据和冻结的人工作决定夹具，不代表真实实验审核，也不能替代研究者复核。
- SteelStats 当前只做描述统计和组级 QC，不做显著性检验、因果判断或工艺推荐。
- Physics Engine 输出是带适用范围说明的经验估算，不是实验真值；缺失输入不会补零。
- Research Agent 可选调用云模型，但只允许读取经审计的结构化摘要。模型回答可能出错，不能直接写入数据、批准映射或启动执行。
- 公开候选仓库不包含真实原始文件、处理后科研数据、运行结果、个人审批记录、模型权重或本机路径。
- 完整 T40 跨模块重放依赖独立的 SteelData 与 SteelStats 项目；只克隆本仓库时可以运行界面、质量门禁和离线测试，但不能凭空重建这两个外部模块。
- 当前主要由单人完成本地 Windows 验收；GitHub Actions 提供 Linux/Windows 自动检查，但仍需要公开发布后的社区环境反馈。
