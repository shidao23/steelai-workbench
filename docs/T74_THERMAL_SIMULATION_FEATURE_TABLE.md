# T74 热模拟特征表

## 目标

把 T73 有效加载段中的关键特征压缩为“一行一个热模拟采集”，供后续统计、报告和受限 Agent 读取，避免每次重复扫描 14,352 个曲线点。

正式目标表为 `data/processed/thermal_simulation_features.csv`。项目负责人已完成 16 个 DH 采集、32 个有效加载段的具名目视复核；正式表现有 16 行。A75 先由页面写入，整批重试时系统正确阻止覆盖，随后只追加其余 15 行。

## 特征内容

每个采集包含：

- 第一、第二道次峰值应力，以及峰值对应的局部真应变和仪器温度。
- 局部真应变 0.05、0.10、0.15、0.20 的流动应力。
- 每道次接触点/终点、起止时间、起点/均值/终点温度。
- 仪器最大 Stroke、相对接触点的最大位移、最大局部真应变。
- T71 复核后的运行温度与道次间隔，以及第二道接触时间减第一道终点时间得到的有效变形间隔。
- 公式版本、分段版本、特征版本、源运行编号、原文件哈希、源点哈希、三份配置哈希、候选段哈希和特征行哈希。

## 确定性规则

定点流动应力只在有效加载段内部计算。相同局部应变的重复采样点先取应力中位数，再在相邻唯一应变点间线性插值；禁止外推。峰值应力使用 T73 基线修正应力，不使用完整回程路径。

所有规则登记在 `config/thermal_feature_extraction_v1.0.json`。目标应变或算法发生变化时必须发布新特征版本，不能静默覆盖既有表。

## 人工审批和正式写入

工作台“数据与物理 → 数据接入与质控 → 热模拟曲线”显示当前选择的候选特征。复核人需目视确认两道次接触点、卸载前终点、曲线方向和异常点，填写具名身份与批准依据后，系统才会：

1. 把精确候选摘要与审批记录绑定。
2. 将 `segment_review_status` 改为 `approved`。
3. 通过共享 Research Data Contract 重新校验。
4. 只追加写入正式特征表。
5. 生成 Governance Manifest 和复核证据包。

同一 `experiment_run_id + feature_version` 不允许覆盖或重复写入。

## 当前状态与边界

正式写入治理记录为 `INTAKE-1ED5882C1521A2760C77`。T74 不计算 0.2%/2% 偏移屈服应力、软化率或再结晶动力学参数。特征表中的峰值与定点流动应力是确定性派生量，不是新的原始实验测量。摩擦修正、绝热温升修正和异常点处理仍未启用。
